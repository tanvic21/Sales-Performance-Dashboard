# Sales Performance Dashboard Analysis

## Project Overview
This project analyzes retail sales data using Power BI to generate business insights related to sales, profit, quantity, and regional performance.

## Tools Used
- Power BI
- Excel
- Power Query

## Features
- KPI Cards for Sales, Profit, and Quantity
- Sales by Category Analysis
- Sales by Region Visualization
- Profit by Category Donut Chart
- Interactive Segment Filter

## Insights
- Identified top-performing categories
- Compared regional sales performance
- Analyzed category-wise profit contribution
- Enabled dynamic filtering using slicers
